# Scene editing contract: clip replacement

This bounded extension uses the existing Streamlit Scene Editor, scene plan,
generation manifest and MoneyPrinter composer. It does not select a new editor
framework or project interchange format.

## Asset and timing contract

- A replacement is an explicitly uploaded MP4, at most 100 MiB. The upload's
  filename and original host path are never persisted. Task and scene IDs must
  resolve to an existing task and scene before files are written.
- The clip must decode, match the scene aspect, and cover its existing duration.
  FFmpeg trims from the start, normalizes to H.264/yuv420p and removes audio.
  There is no speed change, looping, new narration or timeline-duration edit.
- Only validated media becomes a new `generated_ai/scene-NNN/vNNN.mp4` version.
  Existing versions remain available under the normal cleanup policy.
- Additive version metadata records `asset_origin=imported` and
  `import_metadata.media_sha256`. Missing origin means `generated` for existing
  manifests. Generation settings remain the scene's regeneration recipe, not
  a claim that the uploaded media was generated by that provider. Public
  material provenance identifies imports as `manual_upload`.

## Change impact and recovery

| Action | Video inference | Narration/captions | Composition |
| --- | --- | --- | --- |
| Replace clip | None | Reuse | Rerender |
| Restore generated/imported version | None | Reuse | Rerender |
| Prompt/seed regeneration | Selected scene only | Reuse | Rerender |
| Existing render-only changes | None | Reuse | Rerender |

Replacement does not change `scene_plan.json`, the script or task settings.
Render failure rolls back the active manifest and prior final/combined outputs.
Successful edits refresh material provenance and the existing artifact index.
They never submit a publishing job.

Resume revalidates imported clips, including their content hash, using generic
media validation rather than a model-specific output validator. Imports remain
selected across model fingerprint changes, provided the scene identity,
narration segment, aspect and target duration still match. A missing, damaged
or incompatible import blocks Resume with guidance to replace it or restore a
valid version. It is never silently substituted with AI footage. Explicit
regeneration switches the new active version back to generated provenance.

## Acceptance

CPU fixtures must exercise real media normalization and composition, version
restore in both directions, restart/Resume with mixed generated/imported clips,
invalid upload rejection, checksum failures, render rollback and queue failure.
Assertions must cover no video/TTS/caption/BGM generation on replacement,
unchanged unrelated scenes/audio/captions, safe task-local paths and truthful
provenance. Existing provider/recovery/cleanup regressions must remain green.
